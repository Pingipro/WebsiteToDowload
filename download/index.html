Pinguva für Windows — Testversion 1.2.1

Pinguva arbeitet mit Ihrer eigenen Datenbank, Ihrer Praxissoftware und Ihren Kalendern. Ihre Daten bleiben dabei auf Ihrem Rechner.

Pinguva herunterladen (Windows, 170 MB) Ohne Installation starten (portable Version)

Pinguva läuft auf einem Windows-Computer. Bitte öffnen Sie diese Seite am PC.

So geht's

  1. Herunterladen

    Klicken Sie oben auf den blauen Knopf. Die Datei landet im Ordner «Downloads».

  2. Installieren

    Doppelklicken Sie auf «Pinguva-Setup-1.2.1.exe» und folgen Sie den Schritten.

  3. Einrichten

    Beim ersten Start erstellen Sie ein Konto und richten Ihre Praxis oder Firma ein.

  4. Verbinden

    Verbinden Sie Ihre eigene Datenbank, Ihre Praxissoftware oder Ihren Kalender.

Windows zeigt eine Warnung?

Das ist bei dieser Testversion normal. Pinguva ist noch nicht digital signiert. Darum kennt Windows das Programm noch nicht und zeigt: «Der Computer wurde durch Windows geschützt».

So starten Sie Pinguva trotzdem:

Weitere Informationen → Trotzdem ausführen

Laden Sie Pinguva nur von dieser Seite herunter. Wer ganz sicher sein will, vergleicht die Prüfsumme weiter unten.

Das brauchen Sie

  • Windows 10 oder 11
  • 64-Bit (das haben fast alle neueren PCs)
  • Internet nur für die KI-Websuche

Ihre Daten bleiben bei Ihnen

Ihre Firmen- und Patientendaten bleiben auf Ihrem Rechner bzw. in Ihrem eigenen Netzwerk. Pinguva lädt keine Patientendaten in eine Cloud.

Fragen oder Rückmeldungen?

Das ist eine Testversion. Es kann noch Fehler geben. Wir freuen uns über jede Rückmeldung – auch über kleine Dinge.
